## 📌 Project Overview
**Cosmetic Insights** is an end-to-end data analytics and web integration project led by **KADALI GEETHA SRAVYA**. It analyzes a dataset of **1,472 cosmetic items** across top brands to uncover pricing distribution, category shares, customer ratings, and skin-type suitability.

The repository is structured strictly following the 7 required project development phase templates.

## ⚙️ How to Run the Web Application

1. **Navigate to Development Phase:**
   ```bash
   cd "5. Project Development Phase"
   ```
2. **Run Flask Web Server:**
   ```bash
   python app.py
   ```
3. **Open Browser:**
   Go to `http://localhost:5000` to view the interactive dashboard, dataset explorer, and Tableau story embed.
